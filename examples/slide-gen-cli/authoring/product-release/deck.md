# 产品发布状态

## Presentation Brief

为发布负责人制作一份深色 16:9 状态简报。第一页概览验证、评审和上线阶段，第二页明确上线窗口、负责人和交付门槛。使用统一的青色、蓝色和紫色状态色，并以 rocket 资源强调发布主题。

## Deck specification

- Page size: 960 × 540
- Typography: Arial for all copy; compact uppercase labels for status metadata
- Palette: `#0D1426` background, `#F7F9FF` primary text, `#9AA7C2` secondary text, and cyan/blue/purple accents
- Resource: page 1 uses `example-tabler-outline/rocket`; page 2 intentionally uses no Resource Library asset

## Page contract

1. `page-01-status.svg`: overall release progress from validation through launch.
2. `page-02-handoff.svg`: launch window, ownership, and the final three delivery gates.
